Petcam Event Watch

clawpiで稼働する犬検知ペットカメラの現行仕様

確認日: 2026-06-13 / 対象ブランチ: master

概要

USBカメラの映像をローカルYOLOで常時解析し、犬の検知イベントだけを SSDへ保存してDiscordへ通知する。映像全体を外部LLMへ送信しない イベント駆動方式である。 

ELECOM USB Webcam
  -> OpenCV / V4L2 capture
  -> Ultralytics YOLO (yolo26n.pt)
  -> dog label filter
  -> hit count + 45-second cooldown
  -> JPEG snapshot + JSONL event log
  -> Discord webhook notification

通知内容

JSONLには、時刻、tick、ラベル、信頼度、クールダウン秒数、 ヒット数、カメラソース、保存画像パスを1イベント1行で記録する。

主要設定値

CAMERA_SOURCE=0
YOLO_MODEL=yolo26n.pt
CONF_THRESHOLD=0.4
ALLOWED_LABELS=dog
MIN_CONSECUTIVE=2
COOLDOWN_SECONDS=45
SNAPSHOTS_DIR=/mnt/claw-warehouse/snapshots
EVENT_LOG_PATH=/mnt/claw-warehouse/events/events.jsonl

Discord webhook URLなどの秘密値は、本仕様書には記載しない。

既知の注意点

  • ヒットカウンタは未検知フレームでリセットされない。設定名は MIN_CONSECUTIVE だが、実際の挙動は前回通知後の 累積ヒットに近い。
  • 全フレームをYOLOへ入力するため、通常稼働時に約2 CPUコアを使用する。
  • 保存データの自動削除、容量上限、日次集計は未実装。
  • オプションLLMによる画像要約は未実装。
